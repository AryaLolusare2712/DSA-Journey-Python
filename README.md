## 🧠 My Problem-Solving Approach

For each problem, I aim to:

1. Understand the problem and its constraints.
2. Identify the appropriate data structure or algorithm.
3. Write a clear and correct Python solution.
4. Consider edge cases and improve efficiency.
5. Analyze time and space complexity.
